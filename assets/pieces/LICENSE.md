# Chess piece artwork

The twelve SVG files in this folder are the standard chess piece set by
**Colin M.L. Burnett ("Cburnett")**, downloaded unmodified from Wikimedia Commons
(`File:Chess_{k,q,r,b,n,p}{l,d}t45.svg`, e.g.
https://commons.wikimedia.org/wiki/File:Chess_klt45.svg).
